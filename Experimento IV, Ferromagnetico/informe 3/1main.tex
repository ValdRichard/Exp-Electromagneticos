\begin{abstract}
 Se caracterizó una ferrita mixta de Mn y Zn a partir de estudiar la dependencia de la magnetización de la muestra con la temperatura. Para ello, se determinó la temperatura de Curie $T_C$ utilizando dos modelos según el régimen considerado: a bajas temperaturas se utilizó la ley de Bloch, de la cual se obtuvo $T_C$ = \SI{1}{\celsius}, mientras que a temperaturas cercanas a las de curie, se empleó el modelo de Heisenberg, obteniendo $T_C$ = \SI{1}{\celsius} y $\beta$ = . De esta manera fue posible determinar la proporción de Mn/Zn de la ferrita según cada modelo, el cual resultó ser de 0.5 para el modelo de Bloch y 0.6 para el modelo de Heisenberg, lo que se encuentra dentro del rango esperado para este tipo de materiales.
\end{abstract}
